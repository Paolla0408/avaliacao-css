# 🍣 Sakura Sushi

O **Sakura Sushi** é um site de restaurante japonês desenvolvido em **HTML e CSS**, com um design moderno e elegante nas cores preto e vermelho.

O projeto foi criado com o objetivo de apresentar um restaurante japonês de forma visualmente atrativa, contendo informações sobre pratos, cardápio e detalhes dos produtos oferecidos.

## 📌 Funcionalidades do Site

- Página inicial com apresentação do restaurante
- Navbar presente em todas as páginas
- Cardápio com diversos pratos japoneses
- Página de detalhes dos pratos
- Botões interativos com efeitos hover
- Animações em botões
- Imagens com efeito de zoom ao passar o mouse
- Layout moderno e responsivo

## 📂 Estrutura do Projeto

O projeto é dividido em 4 arquivos principais:

- `index.html` → Página inicial do restaurante  
- `cardapio.html` → Exibição dos pratos disponíveis  
- `detalhes.html` → Informações detalhadas dos pratos  
- `style.css` → Estilização completa do site  

## 🍱 Pratos Disponíveis

O cardápio possui diversos pratos da culinária japonesa, como:

- Sashimi
- Hot Roll
- Temaki Salmão
- Sushi Especial
- Yakisoba
- Uramaki
- Gyoza
- Missoshiru
- Combo Sakura

## 💻 Tecnologias Utilizadas

- HTML
- CSS
- Google Fonts

## 🎯 Objetivo do Projeto

Criar um site temático de restaurante japonês utilizando os conceitos aprendidos em sala, aplicando **estruturação HTML**, **estilização CSS**, **hover effects**, **animações**, **cards**, **navbar** e organização visual do conteúdo.
